为何使用栈？

遇到暂时不能输出的运算符就保存，等到优先级或括号要求它完成时再弹出。后进先出与嵌套子表达式的处理顺序一致。

复杂度

每个 token 至多进行常数次入栈、出栈操作：时间 O(n)，最坏辅助空间 O(n)。

支持非负整数、小数、括号及二元 + - * / ^；^ 为右结合。不支持一元负号、隐式乘法和科学计数法。后缀 token 用空格分隔。
